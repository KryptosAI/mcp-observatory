# v0.2.0 Technical Launch Note

MCP Observatory is a regression-evidence CLI for Node/local-process stdio MCP targets.

What is live in `v0.2.0`:

- seven passing real-server proofs, not just fixtures
- a no-clone packed-install verification path
- clearer startup failure diagnosis when a package does not behave like a plain stdio target

What this release proves:

- some real servers cleanly surface `unsupported` capabilities, and that is useful truth rather than failure
- some third-party servers pass `prompts` or `resources` in ways that change the compatibility picture over time
- startup failures can still be evidence if the report explains what likely happened and what to try next

Good evidence links:

- regression diff: [examples/results/sample-report.md](../examples/results/sample-report.md)
- real-server matrix: [examples/matrix-summary.json](../examples/matrix-summary.json)
- proof index: [examples/INDEX.md](../examples/INDEX.md)
- startup diagnosis example: [examples/artifacts/server-pdf-startup-fail-report.md](../examples/artifacts/server-pdf-startup-fail-report.md)

What this repo still does not claim:

- broad MCP observability
- alternate transports
- deep semantic correctness
- universal compatibility with every MCP package on npm
