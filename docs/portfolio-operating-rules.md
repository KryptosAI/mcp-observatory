# Portfolio Operating Rules

MCP Observatory is the only active commercial bet. The open-source engine remains free; paid work is limited to private readiness reviews, hosted reporting, evidence packs, remediation workflow, and support.

- New features must strengthen the MCP CI release-gate wedge or support a contracted customer.
- mcp-seatbelt is a runtime-enforcement integration, not a separate commercial line.
- agent-obs remains local-first OSS until it has independently verified retention.
- Banksey and other projects receive only security, reliability, legal/customer-obligation, or inbound-support work.
- Every six months, continue full-time work only if Observatory has a paid pilot or a repeatable partner channel.
