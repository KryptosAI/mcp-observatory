# Security Policy

If you discover a security issue in MCP Observatory, please do not open a public issue first.

Instead:

- email the maintainer contact associated with the `KryptosAI/mcp-observatory` repository
- include a clear description, impact assessment, and reproduction details
- attach the smallest artifact or transcript that demonstrates the issue

We will acknowledge receipt, investigate, and coordinate a responsible disclosure path.

## Scope Notes

- The project is CLI-first and stores local artifacts by design.
- Please call out any cases where artifact contents could unintentionally expose secrets or unsafe inherited environment data.
