# Code of Conduct

## Our Standard

We are committed to a welcoming, respectful, and constructive environment for contributors, maintainers, and users.

Examples of expected behavior:

- giving and receiving feedback with care
- assuming good intent while staying honest about technical tradeoffs
- helping others reproduce issues with concrete artifacts and steps
- keeping disagreements focused on the work, not the person

Examples of unacceptable behavior:

- harassment or intimidation
- bad-faith participation
- personal attacks
- publishing private information without permission

## Scope

This code of conduct applies in project spaces, issues, pull requests, and related public communication.

## Enforcement

Project maintainers may remove comments, contributions, or access that violate this policy.

For serious concerns, open a private report through the security contact in [SECURITY.md](./SECURITY.md).
