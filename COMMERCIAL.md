# MCP Observatory Commercial Offering

MCP Observatory helps platform, security, and engineering owners make a production decision before agents depend on MCP servers.

The open-source CLI and MCP server remain free under the MIT license. The commercial offering packages the same evidence model into a fixed-scope, private release decision for an organization with a near-term MCP approval need.

## MCP Release Gate Pilot

**$15,000 · 1–3 critical MCP servers · 10 business days**

The pilot produces an evidence-backed **approve, gate, or defer** decision, a named remediation list, and a practical CI/SARIF handoff. It is designed for a named platform, security, or engineering owner with active pre-production or production MCP use and a decision expected within 60 days.

The first two qualified founding design partners may receive a $10,000 rate in exchange for structured feedback and permission to publish an anonymized outcome. This is not a public self-serve price.

See the [full offer](./docs/paid-pilot-offer.md), [illustrative evidence pack](./docs/sample-attack-simulation-evidence-pack.md), and [open core and commercial boundary](./docs/commercial-boundary.md).

## What remains open source

- Local CLI checks, safe attack simulation, audit profiles, SARIF, and public Safety Index evidence
- Self-managed artifacts, reports, and public-project CI setup
- MIT-licensed source code and public methodology

## What the pilot includes

- A scoped inventory and review of the agreed MCP servers
- Reproducible safe-mode evidence, including schema/tool drift and declared capability checks
- A decision record with scope, exclusions, verdict, evidence, and named owner actions
- CI rollout guidance, a drift baseline, and SARIF/Code Scanning handoff where applicable
- A readout for the decision owner and the technical team

It is not a penetration test, a compliance attestation, an authorization to operate, a certification, or permission to handle production credentials.

## Expansion comes after delivery

Only after a completed pilot establishes a recurring need, MCP Observatory may scope recurring CI/drift review, private fleet reporting, remediation support, or additional server scope. There is no public monthly plan.
