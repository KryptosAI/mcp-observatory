# Roadmap

## Phase 1: Sharp CLI Core

- stabilize the run artifact schema
- keep `run`, `diff`, and `report` small and credible
- grow a deterministic fixture corpus
- make the Markdown report excellent

## Phase 2: Better Evidence

- richer evidence capture for failures and partials
- stronger corpus organization and fixture discoverability
- more nuanced reporting for recoveries and added coverage

## Phase 3: Broader Reach

- additional adapter types beyond local process
- optional CI helper scripts and integration examples
- optional public site or dashboard only after the CLI is obviously useful

## Good First Issues

- improve one evidence message to be more actionable
- add one reproducible fixture case with docs
- improve one Markdown report section for scanability
- add one integration example for CI artifact handling
